# Project Output

The project was successfully implemented and tested in ServiceNow.

Assignment Group becomes mandatory when Impact is High.

Urgency is automatically set to High.

Urgency becomes read-only for High Impact incidents.

Incident saving is prevented when Assigned To is empty.

State changes through list editing are blocked.

State can still be changed through the Incident form.

The project improves Incident data accuracy and reduces incomplete data entry.
