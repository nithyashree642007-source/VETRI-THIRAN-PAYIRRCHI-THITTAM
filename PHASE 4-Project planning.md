# Project Planning

The project is planned in the following tasks:

1. Create UI Policy – Control Incident fields based on Impact.


2. Create UI Policy Action – Make Assignment Group mandatory and control Urgency.


3. Create onChange Client Script – Automatically set Urgency to High when Impact is High.


4. Create onSubmit Client Script – Prevent saving when Assigned To is empty for High Impact incidents.


5. Create onCellEdit Client Script – Prevent State changes through list editing.


6. Testing – Test all implemented functionalities and verify the expected results.
