# Project Objectives
1. To control Incident field behavior based on Impact.
2. To make Assignment Group mandatory when Impact is High.
3. To make Urgency read-only when Impact is High.
4. To automatically set Urgency to High for High Impact incidents.
5. To prevent saving an Incident when Assigned To is empty for High Impact incidents.
6. To prevent direct State changes through list editing.
    
#Functional Requirements
The system should:
1. Make Assignment Group mandatory when Impact is High.
2. Make Urgency read-only when Impact is High.
3. Automatically set Urgency to High when Impact changes to High.
4. Prevent saving when Assigned To is empty and Impact is High.
5. Prevent State changes through list editing.
6. Allow State changes through the Incident form.
